# EXPERIMENTANDO CON JULES, ANTIGRAVITY Y SLIPLANE

Este proyecto forma parte de mi proceso de aprendizaje y experimentación. 
Se trata de un **portfolio experimental**, creado con el objetivo de **probar y comparar el uso de distintas herramientas de Inteligencia Artificial aplicadas al desarrollo web**, 
así como explorar nuevos flujos de trabajo, formas de generar código y procesos de despliegue dentro del ecosistema web actual.


## Sobre el proyecto

Este portfolio ha sido creado como un espacio para:
- Mostrar mis proyectos y experiencia
- Experimentar con **herramientas de Inteligencia Artificial aplicadas al desarrollo**
- Probar distintos flujos de **deploy y publicación**

He utilizado **diferentes IAs como apoyo creativo y técnico**, entre ellas:
- **Jules** → para generación y estructuración de componentes
- **Antigravity** → para experimentar con enfoques creativos y variaciones de diseño
- **Deploy** → para pruebas de despliegue y publicación del proyecto

El objetivo no es solo el resultado final, sino **aprender, comparar y entender cómo integrar la IA de forma consciente en el desarrollo web**.


## Tecnologías utilizadas

- **React** (con Vite)
- **JavaScript (ES6+)**
- **HTML semántico**
- **CSS modular / Mobile First**
- **Git & GitHub**
- **Herramientas de IA para apoyo en desarrollo y diseño**
