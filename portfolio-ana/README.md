# Personal Portfolio de Ana Aguilera Morales

Este es un proyecto de portfolio personal para Ana Aguilera Morales, una Fullstack Developer junior. El sitio está construido con React y Vite, y estilizado con Tailwind CSS.

## 🚀 Objetivo

El objetivo de este proyecto es mostrar el perfil profesional, los proyectos y la experiencia de Ana, con un enfoque en el desarrollo de soluciones digitales accesibles y con impacto social.

## 🛠️ Tecnologías Utilizadas

- **React:** Biblioteca para construir interfaces de usuario.
- **Vite:** Herramienta de desarrollo frontend moderna y rápida.
- **Tailwind CSS:** Framework de CSS "utility-first" para un diseño rápido y personalizado.

## ✨ Características

- **Diseño Responsivo:** Totalmente adaptado para una visualización óptima en dispositivos móviles, tablets y de escritorio.
- **Accesibilidad:** Construido con HTML semántico y buenas prácticas de accesibilidad (a11y) para garantizar que sea usable por el mayor número de personas posible.
- **Componentes Modulares:** La aplicación está dividida en componentes reutilizables y bien organizados.
- **Scroll Suave:** Navegación fluida entre las diferentes secciones de la página.

## 📂 Estructura del Proyecto

El proyecto sigue una estructura de carpetas lógica y escalable:

```
src/
├── components/   # Componentes de React
├── data/         # Datos estáticos (proyectos, experiencia)
├── App.jsx       # Componente principal de la aplicación
└── main.jsx      # Punto de entrada de la aplicación
```

## 🏃‍♀️ Cómo ejecutar el proyecto localmente

1.  Clona el repositorio.
2.  Instala las dependencias: `npm install`
3.  Inicia el servidor de desarrollo: `npm run dev`
4.  Abre tu navegador en `http://localhost:5173`

## 📦 Cómo construir para producción

Para crear una versión optimizada para producción, ejecuta:

```
npm run build
```

Esto generará los archivos estáticos en el directorio `dist/`.
